   275→## 7. Dokumentasi API
   276→
   277→Semua endpoint berada di bawah `src/app/api/`, tervalidasi Zod, dan tersambung ke Prisma.
   278→
   279→### 7.1 `POST /api/leads` — Capture Lead
   280→Form Hero & Final CTA. Normalisasi WA otomatis + estimasi nilai kontrak per paket.
   281→
   282→```jsonc
   283→// Request
   284→{
   285→  "name": "Andi Wijaya",
   286→  "whatsapp": "0812-6999-9910",      // → dinormalisasi "6281269999910"
   287→  "sector": "kuliner",
   288→  "message": "Butuh NIB + Halal untuk kafe",
   289→  "package": "bisnis"                // umkm | bisnis | enterprise
   290→}
   291→// Response 201
   292→{ "id": "clx...", "estimatedValue": 3500000, "status": "new" }
   293→```
   294→
   295→### 7.2 `POST /api/chat` — RIZKI AI
   296→Konsultan AI percakapan. Menyimpan riwayat per `sessionId`, **mendeteksi nomor WA** di teks → simpan lead, dan menerima `language` agar jawaban ditulis dalam bahasa pengunjung (dapat diganti di tengah sesi).
   297→
   298→```jsonc
   299→// Request
   300→{ "sessionId": "abc123", "message": "How much for a PT?", "language": "en" }
   301→// Response
   302→{ "reply": "A PT (Perseroan Terbatas) typically costs between Rp 3.5–7 million…", "language": "en" }
   303→```
   304→
   305→### 7.3 `POST /api/license-checker` — Analisis Izin AI
   306→Deskripsi usaha bebas → roadmap perizinan JSON terstruktur (NIB, UIK, Halal, BPOM, PBG, dst.) + estimasi biaya/waktu, dicatat ke tabel `LicenseCheck`.
   307→
   308→```jsonc
   309→// Request
   310→{ "description": "Kedai kopi dengan 5 cabang di Bandung", "whatsapp": "0812xxxx" }
   311→// Response
   312→{ "roadmap": [{ "step": 1, "permit": "NIB", "cost": "Gratis", "duration": "1 hari" }, …] }
   313→```
   314→
   315→### 7.4 `GET /api/subscribe` / `POST /api/subscribe`
   316→Kursus email 7 hari. `POST` melakukan **upsert anti-duplikat** via email; `GET` mengembalikan `count` (dengan baseline 1.200) untuk social proof live.
   317→
   318→### 7.5 `GET /api/stats`
   319→Counter social proof: jumlah klien, izin diproses, provinsi (38) & kab/kota (514) — data baseline di server, ter-cache memori.

   345→## 9. Sistem Multibahasa (30 Bahasa)
   346→
   347→### 9.1 Arsitektur
   348→
   349→```
   350→?lang=xx (URL)  ─┐
   351→localStorage     ├─►  language-provider.tsx  ─►  <html lang dir>  +  t(key)
   352→"pp-lang"        │      deteksi berlapis         sinkron otomatis     fallback:
   353→navigator.langs  ─┘      (SSR-safe: id dulu,       (RTL otomatis       xx → id → key
   354→                          queueMicrotask)          untuk 4 bahasa)
   355→```
   356→
   357→- **Kontrak tipe** `Translation` = **146 key** × 30 bahasa — divalidasi script terpusat: `30/30 bahasa, 146/146 key, 0 missing`
   358→- **Fallback berlapis**: `t(key)` → bahasa aktif → `id` → key mentah — mustahil teks kosong
   359→- **Token dinamis**: `{p}` (paket), `{n}` (angka), `{name}` (nama pengguna), `{year}` (hak cipta)
   360→- **RTL penuh**: `dir="rtl"` disetel otomatis untuk **ar, fa, ur, he** — seluruh layout ter-mirror (logo kanan, form terbalik) tanpa CSS tambahan
   361→- **Persistensi**: pilihan tersimpan di `localStorage("pp-lang")`, dipulihkan antar-navigasi
   362→
   363→### 9.2 30 Bahasa yang Didukung
   364→
   365→| # | Kode | Bahasa | Penutur | RTL |
   366→|---|------|--------|---------|:---:|
   367→| 1 | `id` 🇮🇩 | Bahasa Indonesia — **default** | 199M | — |
   368→| 2 | `en` 🇬🇧 | English | 1,515M | — |
   369→| 3 | `zh` 🇨🇳 | 中文 (Mandarin) | 1,140M | — |
   370→| 4 | `hi` 🇮🇳 | हिन्दी (Hindi) | 609M | — |

   585→## 17. FAQ Proyek
   586→
   587→<details>
   588→<summary><b>Mengapa satu halaman, bukan multi-rute?</b></summary>
   589→Semua aset SEO terkonsentrasi pada satu URL berotoritas tinggi (anchor + JSON-LD + peta situs HTML), sementara fase 5-6 membuka rute programmatik saat domain live — strategi dominasi SERP dua gelombang.
   590→</details>
   591→
   592→<details>
   593→<summary><b>Kenapa i18n kustom, bukan next-intl/routing per-lokale?</b></summary>
   594→Situs satu halaman + 30 bahasa = 30× duplikasi rute tidak perlu. Provider dictionary + <code>?lang=</code> memberi pengalaman penuh (termasuk RTL) tanpa biaya rute, dan hreflang tetap terdeklarasi di metadata & sitemap. Rute dedikasi direncanakan Fase 6.
   595→</details>
   596→
   597→<details>
   598→<summary><b>Apakah konten Indonesia-only jadi masalah untuk pengunjung asing?</b></summary>
   599→Tidak — 17 layanan, 16 panduan, dan 13 artikel tetap berbahasa Indonesia sebagai aset SEO lokal, dan setiap section konten menyertakan <code>contentNote</code>: RIZKI AI menerjemahkan/menjelaskan konten tersebut dalam bahasa pengunjung secara interaktif.
   600→</details>
   601→
   602→<details>
   603→<summary><b>Bagaimana keamanan API key AI?</b></summary>
   604→<code>z-ai-web-dev-sdk</code> hanya dipanggil di API route (server). Browser tidak pernah melihat kredensial. Semua input divalidasi Zod sebelum menyentuh database.
   605→</details>
   606→
   607→<details>
   608→<summary><b>Bagaimana menambah layanan/provinsi/artikel baru?</b></summary>
   609→Semua deklaratif: tambah objek di <code>SERVICES</code>/<code>PROVINCES</code>/<code>BLOG_ARTICLES</code> — UI, peta situs, JSON-LD, dan cross-link mengalir otomatis.
   610→</details>
